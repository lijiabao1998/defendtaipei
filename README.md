# DefendTaipei-Lab 保衛台北

以真實台北街道為戰場的生存遊戲原型：玩法參考《Project Zomboid》（俯視生存沙盒），但敵人是已經佔領台北的解放軍佔領部隊。你是萬華巷弄裡的倖存者，搜刮物資、避開巡邏、一區一區奪回街區。

**線上遊玩：** https://game.lijiabao.uk/defendtaipei/（遊戲總站 https://game.lijiabao.uk/ ；舊網址 https://lijiabao1998.github.io/DefendTaipei-Lab/ 會自動轉址）

## 語言 / Language

可在標題畫面或「設定」選擇 **English／繁體中文**，切換會重新載入；一般單人遊戲會先存檔並續玩。預設維持繁體中文，既有存檔 ID 不變。原場景招牌與歷史紀錄保留原文。驗證界線見 [English localization notes](docs/ENGLISH-LOCALIZATION.md)。

## 開發
```
npm install
npm run dev                      # 開發伺服器
npm run typecheck                # TypeScript 型別檢查
npm run format                   # Prettier 排版（設定在 .prettierrc.json）
npm run build && npm run smoke   # 建置後跑冒煙測試（Playwright：選角、序章、移動、背包、搜刮、夜間）
npm run fetch-osm                # 重新從 Overpass API 抓取地圖
node scripts/tiles.mjs           # 重新切 200 m 道路細節圖塊（public/data/tiles/）
```
- 推到 `main` 會由 GitHub Actions 建置並部署到 GitHub Pages。
- 每個 PR 會自動跑 CI（`.github/workflows/ci.yml`）：型別檢查、排版檢查、不需瀏覽器的檢查（`node scripts/checks/modules.mjs`）、建置，接著平行跑三個瀏覽器測試：冒煙測試、劇情存檔流程、警報測試音。CI 用軟體算圖，全部跑完約 15 分鐘。合併前請等 CI 全綠。
- `scripts/checks/` 是各版本的功能截圖腳本（例如 `node scripts/checks/v18veh.mjs`），需要先 `npm run preview`；截圖存到 `shots/`。共用設定見 `scripts/lib.mjs`：`URL`（遊戲網址）、`SHOTS_DIR`（截圖資料夾）、`PW_CHROMIUM`（沒有安裝 Playwright 瀏覽器時指定 Chromium 路徑）。
- 多人連線伺服器在 `server/`，說明見 `server/README.md`。

## v7 — 時間系統
- 新遊戲可選一天長度 1／2／4 小時（存檔保存）；劇情依遊戲內時鐘。
- 快轉 1x／3x／20x（HUD 按鈕或 1/2/3 鍵），睡覺自動快轉；敵人接近、噪音、受傷時自動降回 1x。
- 宵禁 20:00–06:00：視野縮小、巡邏增加、手電筒光錐。飢餓／口渴／疲勞／腐敗依遊戲時間計算。
- 地下電台廣播、空投事件（紅色煙霧，解放軍會爭奪）、下雨（地面變濕、雨聲）、雨水桶集水（停水後仍可用）。
- 鐵皮／雨遮改為灰綠、青與褪色鐵鏽紅；攤車移至人行道與騎樓；騎樓柱只出現在立面前；空地改為鄰里公園或停車場。
- 路面：裂縫變細淡、油漬變淡、積水只在下雨時明顯、電線不投影、只保留主幹道連續中線、陰影 normalBias。

## v8 — 撤離結局（另一個結局，奪回之路保留）
- **直升機撤離**：第 6 天晚上電台預告；第 7 天 06:00 廣播開啟撤離窗口，至第 8 天 18:00 永久關閉。西側河濱撤離區（綠色 H、橘旗、紅色信號彈）；HUD 顯示剩餘時間。抵達即播放動畫：通用低多邊形直升機接應 → 飛越台灣海峽 → 降落福特號航空母艦（CVN-78）甲板 → 結算卡。
- **聯絡人＋小艇**：每局聯絡人隨機出現在廟口／柑仔店後巷／公園，給出宵禁時段的河岸接頭點。30% 是佔領軍陷阱：假聯絡人說錯街名、要你「一個人來、武器留下」；廟口阿伯會提醒。可事先偵察（廂型車、無拖船痕跡 vs 藏好的橡皮艇）或用收音機／物資向「自由之聲」查證。中陷阱有 3 秒反應時間，可逃進巷子或跳進河；逃脫後該處標為危險區，叛徒躲回街區，抓到他會供出真接頭點或佔領軍前哨（計入奪回）。看穿陷阱可反伏擊並取得裝備箱。真聯絡人：小艇沿淡水河出海，與福特號會合。
- 結算卡可選「繼續留在萬華（奪回之路）」或新遊戲。

## v12 — FPV 自殺無人機與解放軍偵察無人機
- 零件（無刷馬達×4、4S 鋰電池、類比圖傳、碳纖機架）散落民宅／警局；使用機架＋手榴彈組裝。成品 FPV 也會出現在空投與士兵（特戰更常見）遺留裝備中。一次性。
- 駕駛視角：類比圖傳雜訊／色偏／雪花、OSD（RSSI 訊號格、LQ、電壓／電量、高度、速度、油門、計時）。電池約 2.5 分鐘。
- 操控：桌機滑鼠俯仰／滾轉、W/S 油門、A/D 偏航、Esc 放棄（指標鎖定）；手機雙搖桿（左＝油門／偏航、右＝俯仰／滾轉）。有慣性、重力、陣風（下雨更強）。
- 訊號隨距離與建築遮擋衰減，解放軍檢查哨的干擾站附近壓制訊號，可能斷訊墜毀。
- 撞擊即引爆；從上方俯衝命中裝甲車頂可擊毀（主要反裝甲手段），側面撞擊傷害較低。
- 解放軍偵察無人機盤旋並有嗡嗡聲；在空曠處被盯上約 2.5 秒會招來砲擊與巡邏隊，躲進騎樓或室內可避免。

## v13 — 國軍、戰車支援與「奪回萬華」結局
- 國軍武器（5.56×45mm NATO，與解放軍 5.8×42mm 不通用）：T91、T65K2、T75 班用機槍、T93 狙擊槍（7.62×51mm）、T75 手槍（9mm）；反裝甲：紅隼（可裝填）、AT4（一次性）、標槍（稀有，頂部攻擊）。
- 觸發一：奪回第 2 個街區後，「自由之聲」通報國軍特戰在附近；據點出現國軍補給箱，空投開始帶國軍武器，附近有受傷聯絡官的背包（損壞無線電）。

- 二樓算室內，可以睡覺；佔領軍追不上來，但下樓回到一樓時他們可能還在附近。
- 在二樓存檔會記在一樓樓梯口；讀檔後從樓梯口開始。地圖串流、街名和地圖上的位置都以樓梯口為準，所以一樓不會被卸載。
- 容器 id：核心街區 `u<建築>_<n>`；外圍街區 `t<街區>:<20000 + 64×建築序號 + n>`，跟街區一起存檔。

## v23.5.0 — 槍械模型、射擊後座、飽足回血

- 槍械模型（`src/npc/firearms.ts`）：以前只有通用的「突擊步槍」和「手槍」有模型，QBZ-191、T91、T93、QSZ-92 等 16 把槍裝備後手上是空的（敵方狙擊手的 T93 也是）。現在每把槍都有自己的低多邊形模型，從上往下看也分得出來：手槍有滑套、扳機護弓和照門準星；T91 是平頂導軌加翻轉照門，T65K2 有提把；QBZ-191／QBU-191 是全長導軌（QBU 加長槍管和瞄準鏡）；QBZ-95-1／QBU-88 是無托，彈匣在握把後方；T93 有狙擊鏡、拉柄和摺疊腳架；QJY-88 有左側彈鏈箱，T75 是彈匣在下方，兩者都有腳架；QCW-05 有一體式消音器；QBS-09 有管狀彈倉和泵動護木；紅隼、AT4、標槍是發射筒。每把槍合成一個網格（一次繪製），所有角色共用。佔領軍一部分改拿無托的 QBZ-95-1。
- 射擊動作（`src/npc/human.ts`）：每發都會讓槍口上揚、槍往後頂進手裡、手臂和胸口被推回，還有左右抖動；連發時累積「熱度」，槍口持續上抬、肩膀繃緊、整個人往後頂，放開扳機後很快恢復。手槍上揚較大，狙擊槍和霰彈槍單發後座最重，機槍身體吃力最多，衝鋒槍最穩。
- 每一發都有槍口火光（消音衝鋒槍幾乎沒有）和照亮周圍的閃光，彈殼從槍的右側拋出、彈跳後留在地上一會兒（霰彈槍是紅色彈殼），玩家開槍時有輕微畫面震動（只是位移，鏡頭設定不變）。佔領軍開槍也有同樣效果（玩家 30 m 內）。
- 自然回血：飽足和水分都在 50 以上、沒有流血時，每遊戲小時回 6 點（同以前）；兩項都在 80 以上時加快到每小時 18 點，狀態列顯示「飽足・回血中」。
- 檢查：`scripts/checks/v235guns.mjs`（每把槍都有模型、機槍連發的熱度／彈殼／火光、放開後冷卻、回血分級和提示；CI 也會跑）。

## v23.6.0 — 學校、醫院、廟、市場、警察局、辦公室的專屬佈置

- 建築類型取自 OSM 的 building／amenity 標籤（外圍街區資料原本就有，不需重新產生地圖資料），核心街區依名稱判斷（醫院、宮、寺、派出所、分局、圖書館…）。這些公共建築一定可以進入，也放寬到 6000 m²、14 層以下；有二樓的話，二樓也是同一種佈置。
